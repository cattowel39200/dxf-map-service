# 운영 안내

서비스를 시작한 뒤, 고치고 올리는 방법을 적어 둔다.
2026-08-06 기준.

---

## 1. 사장님이 직접 하시는 것

관리페이지 <https://ks-down-map.com/admin> 에서 바로 바꾸실 수 있다.
**코드를 고칠 필요도, 서버를 다시 띄울 필요도 없다. 저장하면 끝이다.**

| 무엇 | 어디서 | 어디에 반영되나 |
|---|---|---|
| 정품 금액 | 판매 설정 | 소개 페이지 · CAD 정품신청 창 |
| 입금 계좌 | 판매 설정 | 소개 페이지 · CAD 창 · 데모 안내 메일 |
| 공지사항 | 공지사항 | 웹 접속 시 팝업 · 공지 게시판 |
| 정품 전환 | 사용 신청자 | 그 고객의 키가 즉시 무기한이 됨 |
| PC 해제 | 사용 신청자 | 고객이 PC 를 바꿨을 때 |
| 세금계산서 발급완료 | 사용 신청자 | 처리 기록용 |

**금액을 바꿔도 이미 접수된 정품신청은 접수 시점 금액을 지킨다.**
신청해 두고 입금하러 간 사이 값이 오르면 안 되기 때문이다.
새 고객에게는 바뀐 금액이 바로 나간다.

---

## 2. 저에게 말씀하시는 것 — 코드를 고쳐야 하는 일

화면 모양, 새 기능, 오류 수정은 제가 고친다. 고친 것이 고객에게
닿는 길은 셋으로 나뉘고, **셋 다 사장님이 하실 일은 없다.**

| 무엇을 고쳤나 | 고객에게 닿는 방법 | 걸리는 시간 |
|---|---|---|
| 웹 화면 · 서버 기능 | 새로고침하면 끝 | 즉시 |
| CAD 리습 | `지적도업데이트` 명령, 또는 켤 때 하루 한 번 알림 | 고객이 받는 대로 |
| 설치 프로그램 | 새로 내려받는 분부터 | 즉시 |

### 말씀하실 때 이렇게 주시면 빠릅니다

- **화면 캡처** — 말로 설명하는 것보다 훨씬 정확하다
- **오류 문구를 그대로** — AutoCAD 명령창에 나온 글자를 그대로
- **무엇을 눌렀더니 어떻게 되었는지** — "A 를 눌렀더니 B 가 나와야 하는데 C 가 나왔다"

### 고친 뒤 확인하시는 법

- **웹** : `Ctrl` + `F5` (그냥 새로고침으로 안 바뀌면 이걸로)
- **CAD** : 명령창에 `지적도업데이트` → AutoCAD 껐다 켜기

## 3. 판 번호와 파일 — 제가 지키는 규칙

리습을 고칠 때마다 판 번호를 올리고 **다섯 곳을 같은 바이트로** 맞춘다.
어긋나면 옛 판이 도는 사고가 난다(2026-08-06 에 실제로 겪었다).

```
%APPDATA%\Autodesk\ApplicationPlugins\CADMAP.bundle\Contents\CADMAP.lsp  ← 실제로 로드
%LOCALAPPDATA%\KyoungsungEng\CADMAP\CADMAP.lsp                           ← 보관용
dxf-map-service\installer\CADMAP.lsp                                     ← exe 에 묶임
dxf-map-service\web\dist\CADMAP.lsp                                      ← 자동 업데이트로 내려감
dxf-map-service\cad\CADMAP.lsp                                           ← 저장소 보관
```

판 번호는 **세 곳이 같아야** 한다 — 리습 `*cm:version*`,
`web/dist/version.json`, `installer/install.py`.
`installer/build.py` 가 다르면 빌드를 거부한다.

## 4. 문제가 생겼을 때

### 사이트가 안 열린다
1. **1분만 기다린다** — 감시 작업이 스스로 되살린다
2. 그래도 안 되면 **PC 를 재부팅하고 로그인** — 로그인하면 자동으로 뜬다
3. 그래도 안 되면 저에게 말씀

### CAD 에서 지적도 메뉴가 없다
1. 명령창에 `지적도메뉴` 입력
2. 그래도 없으면 `install.exe` 를 **AutoCAD 를 닫은 채로** 다시 실행

### 고친 뒤 오히려 나빠졌다
모든 판이 깃에 남아 있다. **이전 판으로 되돌릴 수 있으니** 말씀만 주시면 된다.

## 5. 절대 건드리지 마실 것

| 파일 | 왜 |
|---|---|
| `.env` | V-World 인증키 · 메일 비밀번호 · 관리자 암호가 들어 있다 |
| `data\usage.db` | 발급한 키와 고객 기록의 원장. 이것이 날아가면 고객 라이선스가 사라진다 |
| `ops\` 안의 파일 | 서버·터널 자동 시작과 백업이 여기 걸려 있다 |

`data\backup\` 에 날마다 03:00 에 DB 사본을 뜬다(14벌 보관).
프로젝트 폴더가 OneDrive 안에 있어 클라우드에도 함께 올라간다.

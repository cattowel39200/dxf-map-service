CAD를 켠 채로, 지적도를 도면에 바로 넣으세요

웹에서 내려받고 다시 여는 과정이 없습니다. AutoCAD 명령행에 지적도를 입력하고 두 점만 찍으면 그 범위의 연속지적도가 현재 도면에 그대로 삽입됩니다.

3일 무료로 써보기 설치 파일 받기 사용법 보기

영상이렇게 씁니다

사용법 영상은 준비 중입니다.
아래 단계 설명을 먼저 참고해 주세요.

1·2·3세 단계면 끝납니다

1

설치

메일로 받은 압축을 풀고 install.ps1을 마우스 오른쪽 버튼 → PowerShell에서 실행합니다. AutoCAD를 다시 켜면 명령어가 등록됩니다.

2

발급키 입력

명령행에 지도설정을 입력하고 메일로 받은 발급키를 넣습니다. 도면과 같은 좌표계도 이때 골라 둡니다.

3

불러오기

지적도를 입력하고 도면에서 두 점을 찍으면 끝입니다. 필지 경계와 지번이 실제 좌표에 맞춰 현재 도면에 삽입됩니다.

특징무엇이 다른가

좌표계 8종

중부·서부·동부·동해원점, UTM-K, 구지적(Bessel), UTM 52N, 경위도. 도면 좌표계에 맞춰 바로 씁니다.

실제 좌표에 삽입

원점 이동 없이 진짜 좌표로 들어갑니다. 기존 도면 위에 그대로 겹칩니다.

레이어 분리

필지 경계와 지번·지목이 각각 다른 레이어로 들어와 정리가 쉽습니다.

몇 초면 완료

1,300필지 규모도 2초 안팎이면 도면에 들어옵니다.

주소로 찾기

웹 지도에서 지번을 검색하고 즐겨찾기로 저장해 두면 자주 쓰는 곳을 바로 엽니다.

DXF 표준

R12부터 2018까지 버전을 골라 저장합니다. 다른 CAD에서도 열립니다.

설치 파일 받기
설치할 때 파란 경고창이 뜹니다. Windows가 배포자를 모르는 프로그램에 띄우는 화면입니다. 추가 정보 → 실행을 누르면 설치가 진행됩니다.

설치 후 AutoCAD를 다시 켜면 지적도 메뉴가 생깁니다. 실행하려면 메일로 받은 발급키가 필요합니다.

신청이메일만 남겨 주세요

데모 신청

확인 후 발급키와 설치 파일을 메일로 보내드립니다. 보통 영업일 기준 하루 안에 발송됩니다.

남겨 주신 이메일은 발급키 발송과 문의 답변에만 씁니다. 다른 용도로 쓰거나 제3자에게 제공하지 않습니다.

FAQ자주 묻는 질문

데모가 끝나면 다시 설치해야 하나요?

아닙니다. 입금이 확인되면 쓰시던 발급키가 그대로 정품으로 바뀝니다. 프로그램을 다시 설치하거나 키를 새로 받으실 필요가 없습니다.

PC를 바꾸면 어떻게 하나요?

발급키는 처음 사용한 PC 1대에 묶입니다. PC를 교체하셨다면 메일로 알려 주시면 묶임을 풀어 드립니다. 새 PC에서 처음 실행할 때 다시 등록됩니다.

어떤 AutoCAD 버전에서 되나요?

AutoCAD 2013 이후 버전이면 동작합니다. 리습(LISP)을 지원하는 국산 CAD에서도 대체로 쓸 수 있지만 공식 지원 대상은 AutoCAD입니다.

지적도가 실제 측량 성과와 같나요?

아닙니다. 제공되는 자료는 국토교통부 V-World의 연속지적도로 참고용 도면이며 법적 측량 성과가 아닙니다. 경계 확정에는 한국국토정보공사(LX)의 지적측량이 필요합니다.

한 번에 얼마나 넓은 범위를 받을 수 있나요?

1회 1 km²까지입니다. 더 넓은 구역은 나누어 받으시면 됩니다. 도심에서는 1 km²에 필지가 1,300개 남짓 들어옵니다.

# AutoCAD 연동 리습

AutoCAD 안에서 영역을 지정하면 서버에서 지적도를 받아 현재 도면에 삽입한다.

## 설치

### 자동 로드로 등록 (권장)

AutoCAD를 켤 때마다 알아서 불러오게 한다. 한 번만 하면 된다.

```powershell
cd cad
.\install.ps1
```

AutoCAD의 `ApplicationPlugins` 폴더에 번들로 등록한다. 이 위치는 AutoCAD가 기본으로
신뢰하는 곳이라 최근 버전의 SECURELOAD 보안 설정에 걸리지 않는다.

| 명령 | 하는 일 |
|---|---|
| `.\install.ps1` | 설치 |
| `.\install.ps1 -List` | 설치 상태와 원본 갱신 여부 확인 |
| `.\install.ps1 -Uninstall` | 제거 |

설치 후 AutoCAD를 다시 켜면 끝이다. 켜 둔 채로 바로 쓰려면 설치할 때 안내되는
`(load ...)` 줄을 명령행에 붙여넣는다.

리습을 고친 뒤에는 `install.ps1`을 다시 실행해야 반영된다.

### 그때그때 불러오기

`APPLOAD` → `CADMAP.lsp` 선택 → **로드**. 도면을 닫으면 풀리므로 매번 해야 한다.

## 명령어

### 지적도 (DXFMAP)

두 점으로 영역을 지정하면 그 범위의 도면을 받아 삽입한다.

```
명령: 지적도
영역 첫째 모서리:      ← 클릭
반대쪽 모서리:         ← 클릭
선택 영역  450.0 x 380.0 m   =   0.1710 km2
작업 5281590011ab 진행 중.  지역에 따라 1~3분 걸립니다.
    3%  연속지적도 필지 조회
  100%  좌표 변환 및 DXF 조립
완료   1.1초   0.80 MB
삽입을 마쳤습니다.  ZOOM Extents 로 확인하세요.
```

받은 도면은 실제 좌표에 그대로 놓이므로 기존 도면과 바로 겹쳐 쓸 수 있다.
기본값은 삽입 후 자동 분해(EXPLODE)이며, 블록으로 두고 싶으면 `지도설정`에서 끈다.

### 지도설정 (MAPCFG)

```
명령: 지도설정
  서버       : https://map.kyoungsungeng.com
  좌표계     : EPSG:5186   중부원점 (세계측지계)
  추출 항목  : parcel,pnu
  삽입후분해 : 예
바꿀 항목 [좌표계/항목/서버/분해/종료] <종료>:
```

추출 항목은 `parcel`(필지 경계)과 `pnu`(지번·지목) 둘이며 쉼표로 구분한다.
경계선만 받고 지번은 빼려면 `parcel`만 적는다.

### 좌표 (PTLABEL)

클릭한 점에 POINT를 찍고 그 옆에 X·Y 좌표를 문자로 기입한다.
두 줄(X 위, Y 아래) 또는 한 줄 형식을 고를 수 있고, 문자 높이를 물어본다.
엔터나 ESC를 누를 때까지 계속 찍을 수 있다.

## 좌표계를 반드시 맞출 것

**리습은 현재 도면의 좌표를 지도설정의 좌표계로 해석해서 서버에 보낸다.**
도면이 중부원점인데 설정이 동부원점이면 엉뚱한 지역을 받는다.

도면 좌표를 모르겠으면 `좌표` 명령으로 아는 지점을 하나 찍어 값을 확인한다.
중부원점(EPSG:5186) 서울 지역이면 X는 약 20만, Y는 약 55만이 나온다.

| 좌표계 | X 대략값 | 지역 |
|---|---|---|
| EPSG:5186 중부 | 200,000 ± | 서울·경기·충청·전북 |
| EPSG:5185 서부 | 200,000 ± | 서해안 |
| EPSG:5187 동부 | 200,000 ± | 경상·강원 동부 |
| EPSG:5179 UTM-K | 900,000 ~ 1,100,000 | 전국 단일 |

원점이 달라도 X 값대가 비슷하므로 Y 값과 지역으로 구분해야 한다.

## 도면 범위가 지정한 영역보다 조금 넓은 이유

경계에 걸친 필지를 잘라내지 않고 통째로 넣기 때문이다. 실측에서 최대 300 m 정도
넘어간다.
지정한 사각형에 딱 맞춰 자르는 편이 낫다면 서버에서 바꿀 수 있다.

## 잘 안 될 때

**"서버에 연결할 수 없습니다"**
서버가 꺼져 있다. `run.ps1`을 실행한다. 다른 PC의 서버를 쓴다면 `지도설정`의
서버 주소를 `http://그PC주소:8000`으로 바꾼다.

**"요청이 거부되었습니다"**
바로 아래 줄에 원인이 나온다. 영역이 1 km²를 넘었거나, V-World 인증키가
없는 경우가 대부분이다.

**"삽입에 실패했습니다"**
받은 DXF 경로가 함께 표시된다. 그 파일을 `INSERT`나 `DXFIN`으로 직접 열면 된다.
오래된 AutoCAD는 `-INSERT`로 DXF를 바로 못 읽는 경우가 있다.

**한글이 깨져 보인다**
이 파일은 cp949(ANSI)로 저장되어 있다. 편집기로 열어 고칠 때 같은 인코딩으로
저장해야 한다. UTF-8로 저장하면 한글 메시지가 깨진다.

**아무 반응이 없다**
`WinHttp.WinHttpRequest.5.1`과 `ADODB.Stream`을 쓴다. 둘 다 윈도우 기본 구성
요소지만 보안 정책으로 막혀 있으면 동작하지 않는다. 이 경우 웹 화면에서 받아
`INSERT`로 넣는 방법을 쓴다.

## 서버 쪽 변경 사항

리습을 위해 `POST /api/jobs`에 `bbox_crs`를 추가했다. 이 값을 주면 bbox를
경위도가 아니라 해당 좌표계의 평면 좌표로 해석한다. 웹 화면은 이 값을 보내지
않으므로 종전대로 경위도로 동작한다.

```json
{
  "bbox": [201800, 550000, 202250, 550380],
  "bbox_crs": "5186",
  "crs": "5186",
  "layers": ["parcel", "pnu"],
  "options": { "unit": "m" }
}
```

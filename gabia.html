가비아 클라우드란?

가비아 클라우드는 가비아 클라우드 IaaS(서비스형 인프라) 서비스입니다.

사용자가 서버를 직접 구매하거나 소유하지 않고도 원하는 사양의 CPU, RAM, Storage를 설정할 수 있어 자유롭고 탄력적인 서버 운용이 가능합니다.
사용한 만큼만 과금하는 합리적인 요금 정책으로 인프라 비용을 절감할 수 있어 중소·중견 기업의 IT 초기 투자 비용 절감에 효과적입니다.

이런 고객에게 가비아 클라우드를 추천합니다

  • 별도의 투자 없이 경제적인 IT 인프라를 사용하고 싶은 고객
  • 신청 직후 1분 이내로 신속하게 클라우드 서버를 사용하고 싶은 고객
  • 클라우드 도입 후에도 운영·관리와 보안 서비스까지 한 번에 해결하고 싶은 고객
  • 하드웨어 보수 또는 교체 작업 없이 인프라를 편리하게 사용하고 싶은 고객
  • 보안 전문 인력이 24시간 365일 모니터링하는 안정적인 클라우드가 필요한 고객

구성도 및 특징

  • 빠른 서버 설치 및 배포

    원하는 OS 이미지와 사양만 선택하면 최대 10분 이내에 서버 생성 및 이용이 가능합니다.

  • 국내 최초 ‘CSP+MSP+보안관제 전문기업’

    클라우드 도입부터 운영, 관리, 보안까지 모든 여정을 가비아가 함께합니다.

  • 효율적인 단일 컨택 포인트

    외부 업체가 아닌 가비아 직원이 직접 제공하는 매니지드 서비스로 신속하고 정확한 고객 지원 서비스를 보장합니다.

  • 국내 트래픽 최대 4TB 제공

    부담 없는 데이터 전송을 지원하고 히든코스트를 줄였습니다.

  • 해외 트래픽 50GB 제공

    글로벌 진출을 앞둔 국내 중소·중견기업의 진입장벽을 낮추겠습니다.

  • SLA 99.9% 보장

    높은 수준의 월 가용율로 안정적인 서비스 공급을 약속합니다.

  • 정부가 공인한 클라우드 보안

    클라우드 보안인증(CSAP) 획득부터, 클라우드 서비스 품질인증제 최고 레벨(Level5) 획득, 클라우드 서비스 확인제 검증을 통과하였습니다.

FAQ

가비아 클라우드 Gen1(g클라우드)는 가비아에서 2012년부터 제공해온 IaaS 기반 클라우드 서비스 플랫폼입니다.
가비아 클라우드 Gen2는 2025년 새로 출시된 IaaS 기반 클라우드 서비스 플랫폼으로, 가비아 클라우드 Gen1(g클라우드)보다 개선된 기능과 서비스를 제공합니다.

가비아 클라우드 Gen2 서비스 오픈 시점을 기준으로 신규 고객은 가비아 클라우드 Gen2만 이용할 수 있습니다.
기존 가비아 클라우드 Gen1(g클라우드)을 이용중인 고객은 두 플랫폼을 모두 이용할 수 있습니다.(가비아 클라우드 Gen1(g클라우드) 해지 시 다시 신청할 수 없습니다.)
가비아 클라우드 Gen1(g클라우드)는 가비아 클라우드 Gen2 서비스 오픈 시점부터 더 이상 신규 신청할 수 없습니다.
기존 가비아 클라우드 Gen1(g클라우드)를 이용중인 고객만 계속 이용하실 수 있으며, 해당 고객 또한 가비아 클라우드 Gen1(g클라우드) 해지 시 다시 신청할 수 없습니다.
가비아 클라우드 Gen1(g클라우드)보다 더욱 개선된 성능과 유용한 서비스를 제공하는 가비아 클라우드 Gen2 서비스를 이용하시길 권장드립니다.

가비아 클라우드 Gen2 서비스를 이용하려면 신청 정보 입력, 그룹 생성, 휴대폰 인증, 서비스 이용 약관 동의, 결제 방식 등 서비스에 필요한 정보를 입력하고 신청을 완료해야 합니다.
최초 1회의 서비스 신청 및 인증이 완료되면 가비아 클라우드 Gen2의 다양한 자원을 자유롭게 생성하여 이용할 수 있습니다.

[1단계]

  1. 신청 정보 입력: 클라우드 서비스를 이용하게 될 '메인 계정'과, 그 메인 계정이 접속하여 클라우드 서비스를 관리하게 될 '그룹'을 생성하기 위한 정보를 입력합니다.
    그룹을 생성하기 위해 필요한 정보는 다음과 같습니다.
    • 그룹 이름
    • 그룹 뒷자리 주소: 그룹 및 프로젝트의 관리 콘솔에 접속할 수 있는 URL을 정하기 위한 고유한 값입니다.
    • 메인 계정 아이디: 신청하는 클라우드 서비스의 그룹 내 최고 권한을 갖는 계정의 아이디입니다.
    • 메인 계정 비밀번호
  2. 휴대폰 인증
  3. 약관 동의

[2단계]

  1. 결제 정보 선택: 기업 회원일 경우에만 선택할 수 있으며, 개인 회원은 선택할 필요가 없습니다.
  2. 주의사항 확인
  3. 결제 비밀번호 설정: 이미 결제 비밀번호가 설정되어 있는 경우, 설정할 필요가 없습니다.
  4. 결제 수단 등록

2단계를 완료할 경우 클라우드 서비스 신청이 완료되어, 메인 계정과 그룹이 자동으로 생성됩니다.

[3단계]

3단계에서는 별도의 입력 정보가 필요하지 않습니다. 신청 결과에 대해 안내하며, 관리 콘솔로 이동할 수 있는 링크를 제공합니다.

그룹은 가비아 클라우드에서 여러 프로젝트를 하나로 묶어 관리하기 위한 상위 관리 단위입니다.
그룹은 하나의 계정을 기반으로 여러 프로젝트를 통합 관리할 수 있는 환경을 제공합니다.
그룹 콘솔에서는 프로젝트를 생성하거나, 프로젝트의 멤버로 등록할 서브 계정을 관리할 수 있습니다.
또한 리소스 사용 현황 및 요금 데이터, 이벤트 로그를 통합적으로 조회할 수 있습니다.
그룹을 활용하면 여러 프로젝트 간 자원과 사용자를 효율적으로 관리하고, 조직 전체의 클라우드 리소스와 요금을 통합적으로 파악할 수 있습니다.
프로젝트란 가비아 클라우드 플랫폼에서 리소스와 사용자를 체계적으로 관리하기 위해 설정된 작업 단위입니다.
사용자는 그룹 콘솔에서 등록된 서브 계정을 프로젝트에 멤버로 등록하여 관리됩니다.
프로젝트는 독립된 환경으로 설정되며, 리소스와 멤버는 프로젝트 단위로 관리됩니다.
각 프로젝트는 별도의 네트워크, 서버, 스토리지 등의 리소스를 가질 수 있으며, 멤버에게 권한(Role)을 부여하여 작업을 수행할 수 있습니다.
이러한 구조는 다양한 작업과 팀 간의 자원 격리를 가능하게 합니다.
메인 계정은 가비아 클라우드 Gen2에서 그룹과 모든 프로젝트를 관리할 수 있는 최상위 계정을 의미합니다.
메인 계정은 기본적으로 그룹과 프로젝트의 총괄적인 관리 권한을 보유합니다.

[메인 계정의 주요 역할]

  1. 그룹 및 프로젝트 생성: 그룹과 프로젝트를 생성하고, 서브 계정을 관리할 수 있습니다.
  2. 결제 및 요금 관리: 모든 그룹과 프로젝트의 요금 결제 및 관리 작업을 수행할 수 있습니다.
  3. 서브 계정 권한 부여: 서브 계정을 생성하고 필요한 역할(Role)을 부여하여 각 계정의 작업 범위를 설정할 수 있습니다.
메인 계정은 가비아 클라우드 Gen2의 기본 계정으로, 클라우드 서비스 신청 시 입력한 정보로 그룹에 자동 생성됩니다.
메인 계정은 모든 프로젝트에 자동으로 멤버로 추가되고, 역할을 변경하거나 계정을 삭제할 수 없습니다.
서브 계정이란 가비아 클라우드 Gen2 그룹에 속해 있으면서 개별적으로 관리할 수 있는 계정을 의미합니다.
서브 계정은 부여받은 역할(Role)이 가진 권한에 따라 그룹 콘솔 내에서 작업을 수행할 수 있습니다.
서브 계정을 사용하면 하나의 메인 계정을 기반으로 여러 사용자를 개별 관리할 수 있으며, 각 서브 계정에 필요한 권한을 할당하여 자원 접근 및 작업 범위를 제어할 수 있습니다.
예를 들어, 서브 계정에 프로젝트 조회 권한이나 리소스 관리 권한만 부여하여 팀원이 해당 작업만 수행하도록 설정할 수 있습니다.
가비아 계정 하나로 최대 3개의 클라우드 서비스를 가입할 수 있습니다.
동일 계정 내에서 여러 클라우드 서비스에 가입하면, 각각 독립적으로 그룹과 프로젝트를 생성하여 리소스를 관리할 수 있습니다.
이와 같은 구조는 하나의 계정으로도 다양한 클라우드 환경을 분리하고, 서로 다른 결제 수단으로 운영할 수 있도록 설계되었습니다.
단, 계정 관리 및 서비스 관리를 효율적으로 수행하려면 각 서비스 가입 후 그룹과 프로젝트를 명확히 구분하여 관리하는 것이 좋습니다.

3개보다 더 추가로 클라우드 서비스를 더 가입하려면 다른 가비아 계정을 생성해야 합니다.
새로운 결제 수단을 등록하는 경우, [My가비아> 결제 관리> 결제 수단] 에서 카드 또는 계좌 결제 수단을 등록할 수 있습니다.
카드는 휴대전화 인증을 통해 등록할 수 있으며, 계좌는 공동인증서 인증을 통해 등록할 수 있습니다.
클라우드 요금 납부 기간은 매월 10일까지입니다.
매월 1일에 전월 사용량에 대한 청구서가 발행되며, 청구서를 받으신 후 매월 10일까지 납부해주시면 됩니다.
납부기한(매월 10일)까지 비용이 납부되지 않으면 매월 11일에 서비스가 정지됩니다.
서버가 중지된 상태에서도 과금이 발생합니다.
서버가 중지된 상태는 자원이 노드에 점유된 상태로, CPU와 메모리 자원은 유지되며 사양 변경, IP 추가, 스토리지 추가 등이 가능합니다.
따라서 중지 상태에서는 정상 과금이 계속됩니다.

반면, 서버가 종료된 상태에서는 자원이 반납된 상태로, 디스크를 제외한 다른 자원은 점유하지 않습니다.
이로 인해 CPU와 메모리 요금은 청구되지 않지만, VM에 연결된 블록 스토리지나 공인 IP 등 다른 서비스에 대한 요금은 정상적으로 청구됩니다. 종료된 상태는 기간 제한 없이 유지될 수 있습니다.
클라우드 서버는 인터넷이 연결되는 곳이면 어디서나 웹사이트를 통해 필요한 서버 자원을 신속하게 추가하고 관리할 수 있는 서비스로, 무형의 서버 자원을 제공하는 IaaS형 클라우드 서비스입니다.
비즈니스를 위해 개인이 고가의 서버를 직접 구매하거나 소유하지 않고 데이터 저장, 네트워크, 콘텐츠 사용 등 IT관련 서비스를 한번에 사용할 수 있으며, 독립적인환경으로 안정성 및 보안이 강력하고, 구름(Cloud)속에 숨겨진 복잡한 인프라 구조를 알 필요도, 제어(관리)할 필요도 없어 비즈니스에만 집중하기를 원하는 사용자를 위한 서비스입니다.

가비아 클라우드 Gen1은
cloud Infra 통합 매니지드 서비스로 최적화된 IT 인프라 환경의 구축과 운영을 시간당 최저 45원으로 지원합니다.

가비아 클라우드 Gen1 사용자는
자유롭고 탄력적인 서버 자원 확장이 가능하여 유동적인 워크로드(Fluctuating Work Load)에 유연하게 대처할 수 있어 중소 기업의 IT 초기 투자 비용 절감에 효과적입니다.

가비아 클라우드 Gen1 서비스는 사용한 만큼의 비용을 자동 부과하는 후불 결제 서비스입니다.

서비스 비용은 사용한 자원의 시간 또는 월 정액 기준으로 부과합니다.

1개월 이내 사용하면 시간제 비용으로, 1개월을 모두 사용하면 더욱 저렴한 월 정액 비용으로 부과됩니다.

서비스 비용 청구 정책

  • 사용 및 청구 기준은 매월 1일~말일까지 사용한 기간입니다.
    (예: 1월 31일~2월 10일 사용 시 1월 31일 사용은 1월 사용량으로, 2월 1일~10일까지 사용은 2월 사용량으로 인정합니다.)
  • 서비스 비용은 전월에 사용한 시간 또는 기간만큼 산정하여 매월 초에 청구합니다.
    (예: 1월 1일 00시~ 1월 31일 24시의 사용 내역을 2월 1일에 청구합니다.)
  • 사용 시간의 분 단위는 시간 단위로 올림합니다. (예 1시간 40분 사용 시 2시간으로 계산합니다.)
  • 납부 기한은 청구 당월 10일까지입니다
개인은 신용 카드 자동 결제 방식을 사용할 수 있습니다. 단, 연체된 금액에 한해 신용카드, 실시간 계좌이체, 무통장 입금 방식을 지원합니다. 법인 및 단체는 신용 카드 자동 결제 방식과 신용카드, 실시간 계좌이체, 무통장 입금 방식을 지원합니다. 결제 방식은 g클라우드 관리콘솔> 계정관리> 결제방식 관리에서 변경할 수 있습니다.
  1. 신용 카드 자동 결제

    다양한 신용 카드로 자동 결제할 수 있으며, 자동 결제 인증된 카드로 결제됩니다.
    자동 결제를 신청하려면 신용 카드 인증이 필수이며, 인증 시 공인인증서가 꼭 필요합니다.
    가비아는 카드 번호와 개인정보를 저장 및 수집하지 않습니다.

  2. 신용 카드 결제

    다양한 신용 카드로 결제할 수 있으며, 전자 상거래 시 안전하고 편리하게 거래할 수 있도록 안심클릭 또는 ISP 결제를 제공합니다.
    30만 원 이상 결제할 때는 카드용 공인인증서를 반드시 사용해야 합니다.

  3. 무통장 입금

    가비아는 빠르고 정확한 입금 확인을 위해 무통장 입금 시 가상계좌 시스템을 사용하고 있습니다.

    • 가상계좌 시스템이란?
      서비스 주문번호마다 가상계좌를 부여하여 입금자명과 상관없이 실시간으로 입금내역을 확인할 수 있는 자동결제 처리 방식입니다. 부여된 가상계좌는 각 주문번호별 생성되는 일회성 계좌번호로, 하나의 가상 계좌 번호에 중복 입금할 수 없습니다.
  4. 실시간 계좌이체

    자금 이체 방식으로 은행에 따라 인터넷 뱅킹을 신청하지 않아도 실시간으로 결제할 수 있습니다.
    가비아 실시간 계좌이체는 송금수수료가 없고, 공인인증서 없이 이중 암호화 체계를 통해 고객의 정보를 보호합니다.

    • 실시간 계좌이체는 은행별로 결제 가능 시간과 결제 가능 금액이 다릅니다.
    • 시중 일부 은행은 법인 계좌로 계좌이체를 할 수 없습니다.

현재 지원하는 서버 이미지는 리눅스, 윈도우 계열입니다.
편리한 이용을 위해 서버 이미지는 계속 추가할 예정입니다.
원하는 서버 이미지가 없으면 관리자 (cloud@gabia.com) 에게 요청하시기 바랍니다.

가비아 클라우드 Gen1 서비스로 불법 사이트를 운영할 수 없습니다. 불법 사이트 운영이 확인되면 바로 직권 해지가 이루어지며 해지 후 고객에게 통보합니다.
서비스 비용이 연체되면 사용 중인 서비스가 자동으로 중지됩니다. 정상적인 이용을 위해 아래 정책을 반드시 확인하시기 바랍니다.

서비스 정지 정책

  1. 비용 납부기한까지 입금이 확인되지 않으면 체불 상태로 자동 전환되어 서비스 이용이 정지됩니다.
  2. 서비스 정지
    • 청구 당월 납부 기한 + 1일 기준으로 미입금 대상 서비스 정지 처리
    • 가비아 클라우드 Gen1 관리 콘솔의 일부 기능 접속 제한
    • 서비스 정지일 + 7일 기준으로 VM 자동 정지 및 접속제한(RVM 중지). 단, 데이터는 그대로 유지
  3. 서비스 정지 후에도 데이터와 서비스 운영을 위해 보존되는 자원은 비용이 부과됩니다.
  4. 해당 청구 금액이 입금되면 입금 확인 시간 기준으로 서비스를 이용할 수 있습니다. 단, 미납 내역이 남아 있으면 비용 납부가 완료될 때까지 가비아 클라우드 Gen1 서비스를 사용할 수 없습니다.

서비스 해지 정책

  1. 서비스 정지 후 청구 비용을 납부하지 않으면 서비스가 자동으로 해지됩니다.
  2. 서비스 해지
    • 서비스 정지 대상 중 청구월 + 1개월 11일 기준 미입금 대상 서비스 자동 해지 처리
    • 서비스 자동 해지 시 이미 신청한 서버 및 볼륨, 부가서비스 등 모든 g클라우드 서비스 삭제
    • 서비스 삭제 시 사용자의 데이터도 삭제하며 복구 불가능

체불 처리 정책

  1. 입금 안내
    • 매월 8일 기준 미납 고객에게 서비스 정지 및 비용 납부 안내문 발송(메일/SMS)
  2. 비용 연체 시
    • 해당 월 11일 서비스 정지 및 안내문 발송(메일/SMS)
    • 해당 월 + 1개월 6일 서비스 해지 예정 안내문 발송(메일/SMS)
    • 해당 월 + 1개월 11일 서비스 해지 및 안내문 발송(메일/SMS)
  3. 서비스 해지 및 삭제 이후 회사 내부 체불 정책에 따라 채권 추심 등의 절차 진행
  4. 미납 내역이 있으면 가비아 클라우드 Gen1 서비스 이용에 제한이 있을 수 있음

가비아 클라우드 Gen1 Basic과 Premium의 차이는 서버 사양(CPU, Memory)의 차이입니다.

  • Basic : CPU가 8vCore 이하이면서 Memory가 16GB 이하의 사양
  • Premium
    1) CPU가 4vCore 이상의 사양
    2) Memory가 32GB 이상의 사양

※ CPU가 16vCore, Memory가 16GB는 가비아 클라우드 Gen1 Premium 서비스로 설치됩니다.

예) 상품 사양 예시

서버 사양 4vCore + 메모리 8GB = 가비아 클라우드 Gen1 Basic
서버 사양 4vCore + 메모리: 32GB = 가비아 클라우드 Gen1 Premium
서버 사양 16vCore + 메모리: 32GB = 가비아 클라우드 Gen1 Premium

가비아 클라우드 Gen1 Micro는 저사양/고효율 서비스로, 가벼운 웹서버 및 테스트 용도로 부담 없이 사용할 수 있습니다.
일부 기능을 제외하면, 가격 부담 없이 가비아 클라우드 Gen1 Basic과 동일하게 가비아 클라우드 Gen1의 모든 서비스를 이용할 수 있습니다.

가비아 클라우드 Gen1 Micro(HDD) 제약 사항

  1. CPU, Memory 사양 변경을 통해 Basic, Premium 서버로 변경할 수 있습니다. 단, 변경 후에는 가비아 클라우드 Gen1 Micro(HDD)서버로 변경할 수 없습니다.
  2. 이미지 생성 시, 해당 이미지로 동일한 사양의 가비아 클라우드 Gen1 Micro(HDD) 서버만 생성할 수 있습니다.
  3. 위 제약 사항을 제외하고는 가비아 클라우드 Gen1 베이직과 동일하게 가비아 클라우드 Gen1의 모든 서비스를 이용할 수 있습니다.

하이브리드 클라우드는 퍼블릭 클라우드(가비아 클라우드 Gen1)를 가비아에서 제공하는 서버호스팅, 코로케이션 등의 물리적 서버와 연동해서 사용할 수 있는 인프라 구성입니다. 필요한 만큼의 시스템 자원을 자유롭게 확대/축소할 수 있는 클라우드 서버와 보안이 뛰어난 물리적 서버의 장점을 서로 결합한 형태라고 할 수 있습니다.

활용 방안

  1. 중요 데이터의 독립적 보안 강화
  2. 기존 인프라의 확장
    • 현재 이용 중인 서버의 영향 없이 클라우드 서비스와 연동하여 사용 가능
  3. 이벤트 등의 단기적 서비스 런칭
    • 기존의 물리적 서버에서 처리하지 못한 트래픽을 클라우드 서버에서 처리

주요 적용 분야

  1. 금융 / 교육 / 게임 업체 (웹, 모바일, MMORPG)
  2. 서비스의 분리 운영
  3. 대용량 스토리지 운영
  4. 보안 강화 / 재해복구

가비아 클라우드 Gen1드 Basic 서버 생성 시 장착되는 루트 볼륨과 데이터 볼륨의 타입에는 SSD와 HDD가 있습니다.
SSD는 HDD보다 높은 IOPS(Input/Ouput Per Sec: 초당 입/출력 처리 능력)를 기반으로, 뛰어난 성능과 안정성을 자랑합니다.
그래서 분석이나 검색 및 데이터베이스 서버 운용 등 고속의 입출력 처리가 필요한 고객에게 유용합니다.
